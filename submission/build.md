## 의도한 동작

OnGUI 화면에서 목표 1은 좌상단, 목표 2는 우상단, 목표 3은 하단 중앙의 고정 상대좌표에 표시됩니다. 숫자 count, 현재 상태, 다음 목표, 순서 안내와 오입력 메시지를 표시합니다.

- 초기 상태는 `Ready`, count는 `0`입니다.
- `Start`를 누르면 `Playing`으로 전환합니다.
- `Playing`에서 목표를 `1 → 2 → 3` 순서로 누르면 count가 증가하고, 세 목표를 모두 맞히면 `Won`이 됩니다.
- 잘못된 순서의 목표 입력은 count를 바꾸지 않습니다.
- `Restart`는 어느 상태에서나 count를 `0`, 상태를 `Ready`로 되돌립니다. 다시 진행하려면 `Start`를 눌러야 합니다.

## 수동 확인 절차

다음은 앞으로 수행할 확인 절차입니다. Unity 설치·프로젝트 열기·Play·빌드 실행은 모두 **미확인**입니다.

1. Unity `6000.3.22f1`을 사용할 수 있는지 확인하고 이 폴더를 프로젝트로 엽니다. 이 단계의 성공은 아직 검증하지 않았습니다.
2. 새 빈 Scene을 만들고 활성 Scene으로 둡니다. `TinyBeaconGame` 인스턴스는 수동으로 추가하지 않습니다.
3. Console의 컴파일 오류 여부를 확인합니다. 오류가 있으면 아래 예상 동작을 성공으로 기록하지 않습니다.
4. Play에 진입해 Game 뷰에서 자동 생성된 UI, `Ready`, count `0`을 확인합니다.
5. 아래 시나리오를 직접 수행하고 관찰 결과를 별도 기록합니다.
6. Play를 종료합니다. 빌드 여부는 Play 확인과 별도로 기록해야 합니다.

| 시나리오 | 예상 결과 | 실제 검증 상태 |
| --- | --- | --- |
| 빈 Scene에서 Play 시작 | 자동 생성된 UI, `Ready`, count `0`, 다음 목표 `-` 표시 | 미검증 |
| `Ready`에서 `Start` | `Playing`으로 전환, count `0` | 미검증 |
| `Playing`에서 목표 `1 → 2 → 3` | count `1 → 2 → 3`, 마지막 입력 뒤 `Won` | 미검증 |
| `Start` 직후 목표 `2` 또는 `3` | count `0` 유지, 오입력 안내 | 미검증 |
| 목표 `1` 성공 뒤 목표 `1` 또는 `3` | count `1` 유지, 다음 목표는 `2`, 오입력 안내 | 미검증 |
| `Ready`에서 `Restart` | count `0`, `Ready` 유지 | 미검증 |
| `Playing`에서 목표 일부 성공 뒤 `Restart` | count `0`, `Ready`; 다시 `Start` 필요 | 미검증 |
| `Won`에서 `Restart` | count `0`, `Ready`; 다시 `Start` 필요 | 미검증 |
| 에디터 설치·프로젝트 열기·컴파일·실행 빌드 | 각 단계를 실제 환경에서 별도로 확인해야 함 | 모두 미검증 |
